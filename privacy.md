# Hermes privacy policy

Last updated: 26 November 2026

Hermes is a private, self-hosted assistant used by a single household. It is not offered to the public.

**What Hermes accesses.** Hermes accesses only the household's own Google account: Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs and Google Contacts. It does so only after the account owner signs in and approves access.

**How the data is used.** Hermes uses this data only to carry out the household's own requests, such as filing a forwarded booking, adding a calendar event or updating a shared sheet. The data is not used for advertising, is not sold, and is not shared with anyone else.

**Where the data goes.** Data is processed and stored on the household's own server and in its encrypted backups. To understand and answer a request, relevant content is sent to the AI model provider the household uses, under that provider's API terms. Data from Google APIs is not used to train AI models.

**Google API Services User Data Policy.** Hermes's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access.** The account owner can remove Hermes's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
